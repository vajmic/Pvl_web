O projektu

Frontend verze: v4 · live cache + 24 h / 7 dní / 30 dní

Tento dashboard skládá do jednoho pohledu veřejná provozní data Povodí Vltavy, rekonstruované objemové křivky a historický kontext nízkých stavů Orlíku.

Data PVL každých 15 minut načítá GitHub Action do větve data-cache. Pro 24hodinový vlastní graf používáme uloženou časovou řadu; pro 7 a 30 dní zatím zobrazujeme kompletní oficiální grafy PVL, dokud vlastní archiv nepokryje celé období.
