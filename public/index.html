O projektu

Tento dashboard skládá do jednoho pohledu veřejná provozní data Povodí Vltavy, rekonstruované objemové křivky a historický kontext nízkých stavů Orlíku.

Živá data se načítají přes Cloudflare Pages Function, protože přímé čtení pvl.cz z prohlížeče může být omezeno CORS pravidly.
